# Game Sale Tracker Website

A React web application that lets users browse, search, and view video game deals across multiple online stores.
Users can view detailed information about a game, its price history, and be redirected to purchase it.

## Features

Search for games by title

Sort games by price, discount, or rating

Click on a game to view detailed information

View a price history chart for each game

Redirect to the original store page to purchase the game

Data fetched from the CheapShark API
